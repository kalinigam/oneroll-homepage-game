# One Roll Studios — interactive homepage (prototype)

A playable, Mario-style homepage set inside a cozy "studio" room: run/jump
the mascot, bonk the gold ? blocks (the 6 sections), grab coins, stomp the
little creatures, and drop down the pipe toward the studio.

Open `index.html` — or play it live via GitHub Pages.

> Prototype. The pipe / "Enter the studio" targets `room.html` (the agentic
> room), which is the next, not-yet-built piece.
